# Winner AI

מערכת עברית לניתוח טופס Winner 16, יצירת מספר טפסים ומעקב ביצועים. הממשק הראשי הוא "גרסת אבא": טקסט גדול, ניגודיות גבוהה ומעט פעולות.

## כתובות

- גרסת Production: `https://winner-ai-production.up.railway.app/`
- יצירת טפסים: `/builder`
- ביצועים והיסטוריה: `/history`
- בדיקת תקינות: `/health`
- תיעוד API: `/docs`

## יכולות

- טבלת 16 משחקים בעברית.
- מנוע משולב: יחסי שוק, Elo ופואסון.
- יצירת עד 20 טפסים עם פיזור ומניעת כפילויות.
- Backtesting: דיוק, Brier score, Log Loss וכיול.
- למידת דירוגי קבוצות מתוצאות שהוזנו.
- סנכרון אוטומטי עם API-Football, football-data.org, OpenLigaDB ומקור ישראלי ציבורי.
- שמות וכינויים עבריים לקבוצות בישראל.
- בניית מחזור אוטומטי כאשר קיימים 16 משחקים עם יחסי 1/X/2.
- PWA, היסטוריה, גיבוי ומסך ניהול מוגן.

## משתני סביבה

העתק את `.env.example` והגדר לפחות:

- `API_FOOTBALL_KEY` — נתוני ישראל, משחקים ויחסים.
- `ADMIN_PIN` — קוד כניסה למסך הניהול.
- `WINNER_DB_PATH` — נתיב SQLite קבוע. ב־Railway יש לחבר Volume ל־`/data`.
- `BACKUP_DIR` — תיקיית גיבויים. ברירת המחדל היא `/data/backups`.

המשחקים הישראליים הציבוריים ויחסיהם אינם טופס Winner רשמי; כאשר אין יחסי שוק זמינים הם מסומנים ומחושבים כהערכה.

אין לשמור מפתחות בקוד או ב־GitHub.

## מנוע הנתונים החינמי

- מקורות אוטומטיים מותרים: `football-data.org` בשכבה החינמית ו־`OpenLigaDB`.
- נתוני ההתאחדות או מנהלת הליגות נקלטים מקובץ CSV שהמשתמש הוריד כדין. האפליקציה אינה סורקת את האתרים.
- OpenFootball נקלט מקובץ JSON פתוח מקומי. אין שימוש ב־API בתשלום ואין איסוף אגרסיבי.
- לוח ישראל המובנה הוא נתון הדגמה בלבד. ההסתברויות שלו מסומנות כמוערכות ואינן יחסי Winner או יחסי שוק.
- אם מקור נכשל, הסנכרון ממשיך עם המקורות האחרים, מתעד שגיאה, ומשתמש בברירות מחדל שמרניות. נתון ממקור לא מוכר נחסם אוטומטית.
- `GET /api/sources` מציג את המקורות, רמת האמינות ומדיניות הגישה. `POST /api/sources/import` מאפשר למנהל לייבא `official_csv` או `openfootball_json`.
- כיול משקלים חדש מתקבל רק לאחר לפחות 200 משחקים זהים, שיפור גם ב־Brier וגם ב־Log Loss, ומשקלים בגבולות בטוחים.
- הסנכרון האוטומטי רץ כל 360 דקות: ארבע פעמים ביממה. הוא משלב גם Football-Data.co.uk, StatsBomb Open Data, TheSportsDB ו־Open-Meteo.
- `FOOTBALL_DATA_UK_SEASON` ו־`FOOTBALL_DATA_UK_DIVISIONS` שולטים בקובצי ההיסטוריה והיחסים; `STATSBOMB_COMPETITION_SEASONS` מגדיר זוגות `competition_id:season_id`; ו־`THESPORTSDB_LEAGUE_IDS` מגדיר ליגות להעשרה.
- מזג אוויר נאסף רק למשחקים שעבור קבוצת הבית שלהם הוגדרו קואורדינטות ב־`VENUE_COORDINATES_JSON`. הוא משנה את התחזית במשקל קטן ורק בגשם, רוח או חום חריגים.

המערכת מספקת המלצות בלבד ואינה שולחת הימורים.
